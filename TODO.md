## Проверки данных и среды

- [x] ECG-ID: 310 исходных записей; 309 подготовлено. Исключена единственная запись участника без повтора.
- [x] Heartprint v3: импортирован локальный RAR. Из 1539 исходных записей подготовлено 1400; 139 исключено как точные копии сигнала внутри одного ID (135 между S3L и S3R, 4 между S1 и S2).
- [x] PTB-XL 1.0.3: импортирован локальный ZIP. Подготовлены все 5041 запись из целевого поднабора; 2042 участника имеют ЭКГ минимум в два дня.
- [x] Оба разбиения созданы и проверены на всех трёх источниках. Unseen test: ECG-ID — 4 участника, Heartprint — 39, PTB-XL — 408.
- [x] Ручные признаки и PCA: проверочный прогон на всех трёх источниках в обоих протоколах. Корреляция и DTW проверены на реальных парах.
- [x] 1D-CNN: проверочный прогон CPU на ECG-ID и Heartprint, MPS на PTB-XL в протоколе `unseen`. Веса и embeddings сохранены в `runs/smoke/`. Эти прогоны подтверждают запуск обучения, а качество распознавания измеряется отдельно.
- [ ] Запустить тот же проверочный прогон на NVIDIA CUDA. На локальном Mac CUDA недоступна.
