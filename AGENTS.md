# Инструкции для работы над ECG Biometrics

- Прочитай README.md, PROTOCOL.md и TODO.md. PROTOCOL.md — текущее ТЗ и условия эксперимента. Отмечай в TODO.md только проверенные результаты и фактические ограничения запуска.
- По умолчанию используй окружение `marketing`. В проекте Python 3.11+, NumPy, SciPy, scikit-learn, WFDB и PyTorch. Поддерживай MPS, CUDA и CPU. Для ускорителей сохраняй возможность быстрого CPU-теста.
- Храни данные и артефакты в `data/` и `runs/`, вне Git. Не коммить идентифицирующие личные данные, локальные настройки, токены и веса.
- Считай исходную запись атомарной единицей разбиения. Проверяй, что train и query не совпадают по исходному ID и сессии, а протокол новых участников разделён по людям. Не обучай PCA, модель и пороги на тестовых данных. Сохраняй происхождение любого будущего окна.
- При сравнении аугментаций используй одни и те же тестовые запросы и помехи для всех методов. Тестовый шум не должен менять валидацию, эталоны или порог.
- Держи модули небольшими и пользуйся командами `python -m ecg`. Не вводи новые сервисы, схемы конфигурации или крупные зависимости без обсуждения. Согласуй изменения общей схемы данных с командой.
- Для работы в Git используй отдельную ветку. Сохраняй чужие изменения и публикуй изменения только по явному запросу и подтверждению.
- Перед передачей результата запусти релевантные проверки. Стандартный быстрый прогон — `python -m pytest -q`. Для кода данных и моделей важен хотя бы один запуск на реальных данных. Отдельно отмечай, какие GPU действительно проверены.
